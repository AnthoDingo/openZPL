Concevez vos étiquettes ZPL en toute simplicité

openZPL est un éditeur d'étiquettes gratuit et open source pour Windows : texte, codes-barres et images en glisser-déposer, aperçu ZPL en direct et impression directe sur vos imprimantes d'étiquettes.

Télécharger la dernière version Code source sur GitHub

Windows 10 (1809) ou plus récent - 64 bits - installateur autonome, aucun runtime .NET à installer

Génère du ZPL standard

openZPL traduit chaque étiquette en ZPL (Zebra Programming Language), le langage natif des imprimantes d'étiquettes du marché. Le code généré peut être inspecté, copié ou envoyé tel quel à une imprimante compatible.

^FO50,110^BY2

^FDOZ-10492-A^FS
^XZ
