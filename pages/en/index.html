Design ZPL labels with ease

openZPL is a free, open source label editor for Windows: drag and drop text, barcodes and images, live ZPL preview, and direct printing to your label printers.

Download the latest version Source code on GitHub

Windows 10 (1809) or later - 64-bit - standalone installer, no .NET runtime required

Everything you need to design a print-ready label

🖊️

Visual editor

Compose your labels with drag and drop: text, barcodes and images, with layer management and precise alignment.

🔳

Built-in barcodes

Barcode generation via ZXing.Net directly in the editor, no external tool needed.

👁️

Live ZPL preview

Preview the rendered label and the generated ZPL code before printing, avoiding surprises at the printer.

🖨️

Direct printing

Choose the printer and number of copies, then print without leaving the app.

💾

.ozpl files

Save your label templates in a dedicated project format, automatically associated with the app.

🌐

Free and open source

Distributed under the GNU GPLv3 license, open source code available on GitHub.

Generates standard ZPL

openZPL translates every label into ZPL (Zebra Programming Language), the native language of label printers on the market. The generated code can be inspected, copied, or sent as-is to a compatible printer. 

^XA
^FO50,50^A0N,30,30^FDACME LOGISTICS^FS
^FO50,110^BY2
^BCN,60,Y,N,N
^FDOZ-10492-A^FS
^XZ
